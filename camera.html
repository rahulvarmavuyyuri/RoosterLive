      GitHub key

      Needed to save birds to your site. It stays only on this device.

      How to get a key (one time)
      1. Open github.com/settings/personal-access-tokens/new and sign in.
      2. Name it "RoosterLive host" and pick an expiry date.
      3. Under Repository access, choose Only select repositories and pick RoosterLive.
      4. Under Permissions → Repository permissions, set Contents to Read and write.
      5. Tap Generate token, copy it, paste it above and tap Save key.
